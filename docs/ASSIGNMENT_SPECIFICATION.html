Course & Project Objective

Implement classic uninformed and informed search algorithms — Depth-First Search (DFS), Breadth-First Search (BFS), Uniform Cost Search (UCS), and A* Search — and design admissible, consistent heuristics for two structured problem formulations:

  • CornersProblem: Finding a optimal path that touches all four corners of the maze.
  • FoodSearchProblem: Eating all food dots in the shortest path possible.

This is a Group Assignment for teams of 4 members. Students must work together and ensure that every member possesses a complete understanding of the entire solution. Evaluation is conducted both on group deliverables and individual viva/version control contributions.

Graph Search Skeleton Standard

  1. Initialize frontier with the start state: (start_state, path=[]).
  2. Pop a node from the frontier. If state is goal, return action path.
  3. If state has not been expanded before, add to visited set and push successors to frontier.
  4. Repeat until frontier is empty.
  • DFS: util.Stack (LIFO)
  • BFS: util.Queue (FIFO)
  • UCS & A*: util.PriorityQueue (Priority = \(g\) for UCS, \(g + h\) for A*)

Part 2 — Detailed Task Requirements

Q1 — Depth-First Search (4 Marks)

Implement graph-search DFS in search.py using util.Stack. Must maintain a visited set to avoid expanding repeated states.

Q2 — Breadth-First Search (4 Marks)

Implement graph-search BFS in search.py using util.Queue.

Q3 — Uniform Cost Search (4 Marks)

Implement UCS in search.py using util.PriorityQueue ordered by cumulative path cost \(g(n)\).

Q4 — A* Search (4 Marks)

Implement A* Search in search.py using util.PriorityQueue ordered by \(f(n) = g(n) + h(n)\).

Q5 — Corners Problem Representation (8 Marks)

Implement CornersProblem in searchAgents.py. State must be compact and hashable: (position, visited_corners_tuple).

Q6 — Corners Problem Heuristic (8 Marks)

Implement cornersHeuristic in searchAgents.py. Must be admissible and consistent.
