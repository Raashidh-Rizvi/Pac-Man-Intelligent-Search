# Project Overview

> **Module:** IT3012 — Intelligent Agents  
> **Project:** Pac-Man Intelligent Search  

## High-Level Summary
This project focuses on applying state-space search algorithms to solve Pac-Man navigation and food-collection problems. The core objective is to move from basic uninformed search techniques to informed heuristics, ensuring optimal and efficient pathfinding across various maze configurations.

## Question Breakdown
- **Q1:** Depth First Search (DFS)
- **Q2:** Breadth First Search (BFS)
- **Q3:** Uniform Cost Search (UCS)
- **Q4:** A* Search
- **Q5:** Corners Problem (State space search representation)
- **Q6:** Corners Heuristic (Admissible & consistent heuristic)
- **Q7:** Food Heuristic (Complex food collection heuristic)
