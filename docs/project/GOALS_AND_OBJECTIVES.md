# Goals & Objectives

## Primary Technical Goals
1. **Algorithmic Correctness:** Ensure all search algorithms pass 100% of standard autograder tests.
2. **State Space Optimization:** Minimize node expansion counts while preserving search optimality.
3. **Heuristic Admissibility & Consistency:** Guarantee heuristics never overestimate cost ($h(n) \le h^*(n)$) and maintain the consistency property ($h(A) \le c(A, B) + h(B)$).

## Team Collaboration Objectives
1. **Parallel Development:** Work on assigned modules in separate feature branches without blocking dependencies.
2. **Comprehensive Verification:** Validate code quality, edge cases, and performance regressions continuously.
3. **Report & Viva Preparation:** Maintain detailed documentation for individual viva defense and final group reporting.
